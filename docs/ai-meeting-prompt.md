# 会議用プロンプト：「相殺」ローグライトシューター

あなたはゲームデザイナー兼エンジニアとして、開発中のゲームの設計会議に参加しています。
以下は「ここまでの仕様」と「これからの予定」と「議題」です。読んだうえで、議題に答えてください。

---

## 1. コンセプト
- Enter the Gungeon 風の見下ろし型2Dローグライトシューター。
- ドッジロールもブランクも無い。守りの手段は「相殺」だけ。
- 被弾してもすぐにはダメージにならず「予告ダメージ」として積まれ、制限時間内に敵を倒せば打ち消せる。
- キャッチコピーは「被弾上等。撃ち続けて生き残れ」。
- このゲームのミスは「被弾」ではなく「相殺に失敗すること」。すべての設計をこの考え方に合わせる。
- 技術: TypeScript + Vite + Phaser 3。PC（キーボード＋マウス）とスマホ（横向き・タッチ）の両対応。

## 2. 実装済みの仕様（数値は現在の値）

### 操作
- PC: WASD 移動 / マウス照準・左クリック射撃 / 右クリックでダッシュ / R リロード / Q・E 武器切替
- スマホ: 左半分ドラッグで移動スティック、右半分ドラッグで照準（倒している間は射撃）、右下にダッシュ・リロード、右上に武器切替
- ダッシュ: 無敵なし・硬直なし・ダッシュ中も射撃可、0.13秒、クールダウン0.8秒

### 相殺システム（中核）
- 被弾 → HP は減らず「予告」が1つ積まれる。各予告に個別タイマー（初期3秒、アイテム込みでも上限6秒）
- タイマーが0になると「確定」し、HP がハート半分減る（HP はハート3つ = 半分×6）
- 予告は最大4個。それを超える被弾は即確定（上限超過）
- 予告が積まれた直後0.3秒は次の予告が積まれない（同時被弾で一瞬で埋まるのを防ぐ）
- 確定直後は0.8秒無敵
- 相殺ポイント: 撃破で通常1・エリート2。与ダメージでも溜まる（ダメージ150で1ポイント × 武器倍率）。敵の残りHPを超えた分は数えないので、敵1体から出るポイント総量には上限がある
- 1ポイントで予告1つを消す。タイマー残りの少ないものから
- 予告が無い時のポイントは「ストック」として最大1まで保持。ストックは次の被弾を即座に相殺する（自動）
- 連鎖: 直前の相殺から1.5秒以内に次を相殺すると連鎖が続く。2つ以上で成立。連鎖数に応じて、周囲の敵弾を消す衝撃波・敵を押し返す・弾薬回復・一時的な攻撃力アップ（最大+80%、4秒）
- 部屋の敵を全滅させると、残っている予告はすべて消える（相殺には数えない）
- ダメージの種類: 敵弾・接触・爆発・ボス攻撃は予告になる。落とし穴・自分の爆風・HP代償は即確定。火の床は入った時に1回だけ予告を積む

### ミスを認知させる演出（実装済み）
1. 被弾は軽い音と小さな火花だけ。確定はヒットストップ・画面の点滅・重い音
2. 確定の瞬間、その予告を作った敵へ線を引き「時間切れ あと1体」と表示。直後にポイントが入ったら「あと0.4秒」に書き換える
3. 確定理由ごとに色と音を変える（時間切れ=赤、上限超過=紫、即時=橙）
4. 予告がある間、今の武器2発以内で倒せる敵に印を出す
5. 一番早く確定する予告の残り時間に合わせて心音が速くなる
6. 予告は頭上ではなく自機の周りの4分割リングで表示（内側に次の1ポイントまでの溜まり具合、下にストック）

### 武器（2種）
- ハンドガン: 10ダメージ、毎秒5発、10発装填、弾数無限、リロード0.9秒、ポイント倍率1.0
- ショットガン（張り付き型）: 7ダメージ×6粒、毎秒1.7発、射程300px、6発装填、総弾数60、リロード1.3秒
  - 敵との距離でポイント倍率が変わる: 80px以内×2.0 → 160pxで×1.0 → 240px以上×0.3
  - 100px以内で倒すと撃破ポイント +0.5（「至近」表示）
  - 狙い: 範囲攻撃を弱めるのではなく、「張り付いて殴り合うほど相殺が溜まる」個性にする。予告無敵0.3秒と上限4つが殴り合いの限界になる

### 敵（2種）
- 直進撃ち（HP30）: 距離260pxを保って周回し、0.35秒光ってから自機へ1発（弾速210、1.7秒ごと）
- 突進（HP40）: 280pxまで近づくと0.55秒構え（前半は追尾、後半は向き固定）、速度480で0.45秒突進、0.9秒硬直
- 出現から0.8秒は攻撃しない

### フロア
- 1フロア10〜15部屋。格子状のセルに部屋を置き、直線の通路でつなぐ（少しループあり）
- 部屋の種類: スタート / 戦闘 / 宝箱（1〜2、行き止まり優先）/ ショップ1 / ボス（スタートから最も遠い行き止まり）
- 戦闘部屋の40%に火の床か落とし穴
- 入ると扉が閉まり、全滅で開く。ボス部屋クリアで階段 → 次のフロア。3フロアでクリア
- 敵の数: 3 + (フロア-1) + 0〜2体。ボス部屋は1.8倍
- 宝箱は仮で回復＋弾薬補充。ショップ・ボスは未実装

### コード構成
- 相殺ロジック（DamageQueue）とフロア生成は描画から独立しており、Vitest で単体テスト済み（35件）
- 調整用の数値はすべて `src/config/balance.ts`
- 敵・武器はデータ駆動（敵は「行動関数＋定義」で追加）

## 3. これからの予定
- 段階4: 武器・敵・アイテムの追加
  - 武器: マシンガン、レーザー、跳弾銃、ロケットランチャー（計6種）
  - 敵: 扇状に撃つ雑魚、遠くから狙撃するエリート、倒すと弾をばらまく自爆型（計5種）。弾幕は「移動とダッシュだけで避けられるが、避け続けるのは難しい密度」
  - 相殺アイテム: 砂時計（タイマー+1秒）、二重相殺（確率でポイント2倍）、貯蓄の指輪（ストック上限+1）、怒りの予告（予告2つ以上で攻撃力アップ）、連鎖の鐘（連鎖に必要な数-1）、ほか5種を新規提案。重ねがけで相殺が壊れないよう各効果に上限
  - 通貨（敵がドロップ）
- 段階5: ボス（弾幕3パターン、HP段階で切替、一定間隔で雑魚を召喚）、ショップ、タイトル、死亡後のリザルト画面（被弾・相殺・連鎖・確定の理由別内訳、死因の予告がどの敵から来たか、死ぬ直前5秒のスロー再生）

## 4. 未決の論点（すでに出ている案）
- A. 連鎖の鐘: 基本の必要数が2なので「-1」で相殺1回でも連鎖になる。それでいいか（ボーナスは弱め）、基本を3にするか
- B. 部屋全滅で予告が全部消えるのは強すぎないか。代案: 全消去を連鎖として数える
- C. 範囲武器で同時に倒すと、狙わなくても連鎖が出る。残すか、「1発で同時に倒しても連鎖は1段だけ」にするか
- D. ボスが召喚する雑魚を範囲攻撃で倒し続けると無限に相殺できる。召喚雑魚の撃破ポイントを0.5にする案
- E. 突進型に重なると、0.3秒ごとに接触被弾が入り一瞬で溢れる。「同じ敵からの接触は1秒に1回まで」の制限を入れるか
- F. スマホでは横長画面の左右に黒帯が出る。画面いっぱいに広げると見える範囲が機種で変わり、難易度に影響する

## 5. 議題（これに答えてください）
1. **相殺の面白さ**: 今の仕様で「被弾上等で撃ち続ける」遊びになっているか。逃げ撃ちや遠距離からの安全策が最適解になってしまう穴はないか
2. **武器の個性**: 残り4武器（マシンガン、レーザー、跳弾銃、ロケット）を「どこで・どうやって相殺ポイントを稼ぐか」で差別化する案。ショットガン（近距離ほど溜まる）と被らないように
3. **新アイテム5種**: 相殺を軸にした面白いアイテム案。それぞれの上限も
4. **未決の論点 A〜F** への意見と、おすすめ
5. **ボス**: 相殺の仕組みと噛み合う弾幕3パターンと召喚のしかた
6. **その他**: このまま進めたときに一番危ない点を1つ

- 数値を出せるものは、上の現在値を基準にした具体的な数値で
