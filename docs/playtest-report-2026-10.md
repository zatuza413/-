# 自動プレイテストの結果と修正案（2026-10）

## やったこと

- テスト部屋で自動プレイのボットを動かした（合計 約900回）。描画を止め、1/60秒の固定ステップで回している
- ボットの腕前は3段階
  - 初心者: 判断の間隔 0.35秒、弾に気づく確率 70%、照準のぶれ ±7°、ダッシュなし
  - 中級: 0.25秒、85%、±4°、ダッシュあり
  - 上級: 0.15秒、95%、±2.5°、ダッシュあり
- ボットの動き: 予告がある間は近くの雑魚を優先して狙う。武器ごとの距離を保ちながら横に動く。近づく弾を避ける。ボスの返しが光ったら引く
- 2つのモード
  - ボス戦: フロア1のHP1400、HP6、アイテムなし、制限240秒
  - ウェーブ: テスト部屋の5ウェーブ
- 各条件8回。いくつかの調整は、ゲームを動かしたまま数値を差し替えて試した

### 限界

- ボットは壁で跳ねさせて当てられない（跳弾銃の評価は低めに出る）
- 判断がかなり機械的。人間より避け方が一様
- アイテム・フロア2以降・ボス部屋の地形は再現していない
- 数字は「武器や案どうしの比較」として読むこと。絶対値は人間のテレメトリで確かめる

### ショットガンの切り分け（中級、勝率）

| 条件 | 勝率 | 確定被弾 |
|---|---|---|
| 現在 | 25% | 5.4 |

| 距離140で戦う | 0% | 6.0 |
| 上限1.5 | 38% | 4.5 |

死因は返しよりも、「至近で浴びる弾が衝撃波で消えない」と「ポイント不足」の組み合わせ。距離を取ると火力が出ないので、ショットガンには張り付く以外の戦い方がない。

### 通常戦闘（5ウェーブ）

- どの武器・どの腕前でも **被弾の7〜9割をストックが即座に消していた**
- 確定被弾は5ウェーブで平均0〜0.4回、HPはほぼ満タンのまま
- 予告のタイマーが画面に出る場面がほとんどない
  - ポイントの入り（0.3〜0.5/秒）が被弾の間隔（数分に3〜8回）より速いので、ストックが常に満タンになっている

| ストックの案（中級・ハンドガン） | ストックで消えた割合 | 確定被弾/5ウェーブ | 残りHP |
|---|---|---|---|
| 現在（上限1） | 85% | 0.1 | 5.9 |
| 2ポイントで1ストック | 69% | 0.4 | 5.6 |
| ストックの期限3秒 | 87% | 0.1 | 5.9 |
| **ストック上限0** | 0% | 1.6 | 4.4 |

上限0にしたときだけ「予告 → 倒して相殺／間に合わず確定」が通常戦闘で起き始める。
ただしボス戦は厳しくなる（ハンドガン中級 88% → 25%）。

### ロケット・跳弾銃

- ロケット
  - 前回の調整で爆風がボスの弾を消せなくなり、持ち味の「弾消しポイント」がボス戦で消えていた（巻き添え）
  - 消せるように戻すと、ポイントは0.17 → 0.48/秒まで戻る
  - それでも勝てない。確定被弾の内訳に自爆（至近の爆風で即確定）が毎回1〜2回入っている
- 跳弾銃
  - 直撃の倍率0.4では、ボス相手にポイントがほぼ入らない（0.1/秒）
  - 直撃を0.8に上げても勝率0%
  - ボス部屋には跳ねさせる柱がなく、ボスの周りを跳ねて当てるのは人間でも難しいはず

## 修正案（優先順）

### 1. ショットガン対ボスの効かせすぎを戻す（すぐやる）

- ボスへの武器倍率の上限: 1.2 → **1.5**
- 連鎖の衝撃波は、**自機の周り90px以内なら硬い弾も消す**。それより外の硬い弾は消えない
  - 「生まれた瞬間に全部消える」は防ぎつつ、張り付きの自衛は残す
- のけぞらない・張り付きへの返しは残す
- 見込み: 勝率62〜100%、撃破 約31秒（修正前22秒、ハンドガン約60秒）。危険はあるけれど速い、という位置

### 2. ロケットの爆風はボスの弾も消せるように戻す（すぐやる）

- 消せないのは連鎖の衝撃波だけにする
- ロケットの自爆の多さは別に要確認。案は2つ
  - 自爆の半径を60 → 45にする
  - 自分の爆風は「確定」ではなく「予告」にする

### 3. ストックを見直す（要判断・一番大きい）

通常戦闘で相殺の駆け引きがほぼ起きていないのが一番の問題。

- **案A（推奨）**: ストックの基本上限を **0** にする
  - 予告がないときのポイントは端数として残る（1未満）。それ以上は捨てる
  - 「貯蓄の指輪」で初めてストック1。アイテムの価値も上がる
  - 通常戦闘で確定被弾が5ウェーブに1〜2回出て、予告のタイマーが見える
  - ボス戦の補いとして、ボスのポイントを120 → 80ダメージ毎に
  - ハンドガンだけ勝率が低いままなので、ハンドガンの救済が必要。どちらか
    - ボス戦の召喚雑魚を増やす（撃破ポイントの材料）
    - ハンドガンの対ボス倍率を上げる
- 案B: ストックは即座に消さず、「予告が時間切れになる瞬間」に使われる保険にする
  - 予告のリングは必ず見えるようになる。ただし難しさは変わらない
- 2ポイントで1ストック／ストックの期限3秒は、どちらもほぼ効果なし（データ上）

### 4. 跳弾銃のボス戦（人間で確認）

- ボス部屋に柱を2〜4本置く。跳弾にも、ボスの弾を切る遊びにもなる
- または、ボス本体に当たったときは直撃でも倍率1.0にする

### 5. 難しさの段差（観察）

- 通常戦闘はどの腕前でもほぼ無傷。ボスでは初心者のハンドガンが12%
- ストックを見直す（案A）と通常戦闘が少し難しくなり、段差が小さくなる
- ボスはマシンガンが一番速い（33秒）。ハンドガン（60秒）との差は大きい

## 採用した内容（2026-10-16）

ストックは基本なしで決定（「2ストックあったら勝手に連鎖する」ため）。

- ストックの基本上限 1 → **0**（「貯蓄の指輪」で1）
- ストックで消えた予告は**連鎖に数えない**
- ボスのポイント 120 → **80**ダメージ毎
- ボスの召喚雑魚の撃破ポイント 0.5 → **1**（ハンドガンの救済。召喚数を増やす案より初心者に効いた）
- ボスへの武器倍率の上限 1.2 → **1.5**
- 連鎖の衝撃波は、自機の周り **90px** 以内ならボスの硬い弾も消す
- ロケットの爆風はボスの弾も消せるように戻す

### 残っている課題

- ショットガンとマシンガンが対ボスで一番強い
  - ショットガン: 31秒・確定約1回。修正前の22秒・確定0回よりは弱い
  - もっと弱めるなら、ボスへの倍率上限を 1.5 → 1.3 にする
- 跳弾銃とロケットは対ボスで勝てない
  - 跳弾銃はボットが跳ねさせられないので、人間で確認する
  - ロケットは対ボスの火力が低い（約20/秒、マシンガンは約39/秒）
- ボス戦が全体にやさしくなった可能性がある。フロア2・3のHP（1900／2400）でも確かめる

## 再現方法

ボットのスクリプトはリポジトリに入れていない（Playwright が必要）。
`window.__startBot(opts)` をテスト部屋で呼び、`game.loop.sleep()` で通常のループを止めてから `game.step()` を1/60秒ずつ回している。
